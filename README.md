# SWYNEX Task 1 - Data Cleaning & Preparation

## Project Description

This project was completed as part of the SWYNEX Data Analyst Internship - Task 1.

The objective was to clean and prepare a raw dataset for analysis.

## Data Cleaning Performed

The following data-cleaning steps were performed:

- Identified missing values
- Checked for duplicate records
- Corrected inconsistent values
- Cleaned text values
- Standardized date formats
- Corrected incorrect data types
- Checked suspicious/incorrect values
- Prepared the cleaned dataset for analysis

## Tools Used

- Microsoft Excel

- `SWYNEX_Task1_Cleaned_Data.xlsx` - Final cleaned dataset

## Result

The raw dataset was cleaned and prepared for further analysis and visualization.
